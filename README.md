# pm-prompt-library

A suite of prompts for high-leverage product management use cases with AI agents.

## What this is

This is a collection of prompts I’ve developed and refined through hands-on work with AI agents across common product management workflows.

The prompts are designed to help product managers use AI agents for tasks that require more than generating text, including research, analysis, product strategy, requirements, product development, and product communication.

The goal is to make prompts better at giving an agent the context, decision criteria, constraints, and direction it needs to produce useful, decision-ready work.

## Prompt categories

- **Product Discovery** — Competitive analysis, customer/user feedback analysis
- **Product Strategy** — Roadmaps, prioritised backlogs
- **Product Development** — PRDs, MVP builds
- **Product Experience** — UX copy
- **Product Communication** — Product demo scripts, release notes, changelogs
- **Analytics** — Cohorts, dashboards
